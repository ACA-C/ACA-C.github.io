怎么让其它设备也能用？
  • 同一局域网：保持本机开机，用 http://本机IP:8080 打开本页，无需设置。
  • 任意网络：在本机运行 start_web.ps1，它会把页面和 API 一起发布到 https://…trycloudflare.com，用这个地址打开即可。
  • GitHub Pages：打开后在“API 地址”里填上面的隧道地址并加 /v1，保存后即可对话。
